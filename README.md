# Grand Line Services - Discord Vouch Bot 🏴‍☠️

A Discord bot for vouching and reputation management in your community.

## Features
- ✅ Easy vouch system
- 📊 Profile tracking
- 🏆 Leaderboard
- 📈 Server statistics
- 🎯 Simple commands

## Commands
- `!vouch @user service quality prof comm comment` - Vouch for someone
- `!profile @user` - View profile
- `!stats` - Server statistics
- `!top` - Leaderboard
- `!help` - Show all commands
